# Prisma Migrations

Migration files in this directory are auto-generated by Prisma.

**WARNING: Migration files must NEVER be manually edited after creation.**

Editing migration files can cause migration drift between environments and lead to
data loss or failed deployments. If a migration needs to be changed, create a new
migration instead.

To create a new migration:
```bash
npx prisma migrate dev --name <description>
```

To apply pending migrations:
```bash
npx prisma migrate deploy
```
